Mage Survivor 🎮

Mage Survivor is a 2D wave-based survival game developed with Python and Pygame.

This project was created as part of my self-directed journey learning Python and game development. It is my first major programming project and brings together the concepts and systems I learned throughout the project.

🎮 Gameplay

The player controls a mage who must survive 10 increasingly difficult waves of enemies.

Controls

- *Arrow keys* — Move
- *Space* — Shoot / Start the game

Enemies

The game features four different enemy types:

- *Goblin* — Standard enemy
- *Bat* — Faster enemy with lower HP
- *Skeleton* — Ranged enemy that can shoot
- *Slime* — High-HP tank enemy

The game also features a final *Boss* encounter.

⚔️ Game Systems

- 10 progressively more difficult waves
- Player HP and movement speed
- Fireball projectiles
- Enemy HP and collision detection
- Different enemy types with different characteristics
- Enemy health bars
- Player and enemy damage systems
- Game Over system
- Victory system
- Wave progression system
- Random upgrade selection between waves

⬆️ Upgrade System

After completing each wave, the player can choose one of three randomly selected upgrades.

The game currently includes five possible upgrades:

- *+1 Speed*
- *+1 Attack Speed*
- *+1 HP*
- *+1 Fireball Size*
- *+1 Fireball Damage*

📊 In-Game Information

The game displays important gameplay information during each wave:

*Top left*
- Player HP
- Player movement speed

*Top center*
- Current wave

*Top right*
- Fireball damage
- Attack speed
